# 🏆 竞赛信息门户

大学生竞赛一站式平台 —— 竞赛资讯 | 寻找队友 | 资料分享

## ✨ 功能

| 板块 | 说明 | 技术 |
|------|------|------|
| 📋 **竞赛资讯** | 27个主流竞赛信息，筛选搜索，竞赛日历倒计时 | 纯前端 |
| 🤝 **寻找队友** | 发布组队需求，浏览招募信息 | Supabase |
| 📚 **资料分享** | 分享历年真题、获奖作品、备赛攻略 | Supabase |

## 🚀 在线访问

https://jim6642.github.io/competition/

## 📁 项目结构

```
competition/
├── index.html        # 竞赛资讯主页（完整功能）
├── team.html         # 寻找队友
├── resources.html    # 资料分享
├── data.js           # 竞赛数据（27个竞赛）
└── setup.sql         # 数据库建表 SQL
```

## 🛠 本地运行

直接双击 `index.html` 在浏览器中打开即可。

组队和资料功能需要 Supabase 数据库，配置在 `team.html` 和 `resources.html` 中。
